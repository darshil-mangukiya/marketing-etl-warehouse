## 3. Relationship Model Summary

The warehouse relationship guidance is documented in `semantic_layer/star_schema_relationship_map.md` and `semantic_layer/powerbi_tmdl/relationships.tmdl`. Core relationship patterns include:

- `fact_campaign_performance` to `dim_campaign`, `dim_channel`, `dim_date`, `dim_region`, and `dim_device`.
- `fact_leads` to `dim_customer`.
- `fact_revenue` to `dim_product`.
- `fact_attribution` to campaign/source-system structures.

Use single-direction filtering by default unless a dashboard interaction requires a specific exception.

## 4. DAX Catalog Link

Use `semantic_layer/dax_measure_catalog.md` as the measure catalog. Measures include spend, booked revenue, gross margin, ROAS, MER, CPC, CTR, CAC, funnel rates, target attainment, attributed revenue, weighted conversions, and data quality failures.

## 5. KPI Catalog Link

Use `semantic_layer/kpi_catalog.md` for KPI definitions, grain notes, source marts, and reporting rules.

## 7. Validation Checklist

- Import demo mart CSV files from `data/exports/`.
- Confirm date, numeric, and currency data types.
- Create relationships from the relationship map or TMDL scaffold.
- Create measures from the DAX catalog.
- Reconcile visual totals to CSV mart totals.
- Confirm slicers filter expected marts and pages.
- Confirm data quality and source health warnings are visible.
- Label report data as locally generated project data.
