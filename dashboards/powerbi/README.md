# Power BI Dashboard

This folder contains the completed Power BI dashboard and its source-controlled inputs.

## Dashboard File

- `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`

This is the editable Power BI Desktop dashboard file. Open it in Power BI Desktop to review or extend the report.

## Notes

- All report data is generated by the local project pipeline.
- The committed report is an editable Power BI Desktop `.pbix`; cloud publishing and managed refresh are deployment extensions.
- Measures are built from the exported CSV marts listed above.
- The `.pbix` file is the editable dashboard; the dashboard is intended as local project evidence.
- Supporting model documentation lives alongside this README: `data_model.md`, `semantic_model.md`, `relationship_map.md`, `dax_measures.dax`, `power_query_steps.md`, `dashboard_spec.md`, `BUILD_CHECKLIST.md`, `refresh_guide.md`, `performance_optimization.md`, and `rls_mockup.md`.
