# Streamlit BI Dashboard

This local Streamlit app provides a working BI surface for the Campaign ROI Reporting Automation & Marketing Performance Analytics Platform. It reads the generated marts and reporting exports produced by the pipeline scripts.

## Pages

- Executive Overview
- Channel Performance
- Campaign Intelligence
- Funnel Analysis
- Attribution and ROI
- Target vs Actual
- Data Quality and Monitoring
- Customer Value
- Source Health

Each page includes a business question, reusable filters, KPI cards, charts, data tables, and source-mart notes.

## Data Inputs

The app searches these generated output locations:

- `data/exports/`
- `reports/generated/excel_ready/`
- `reports/generated/`
- `release/site/data/`
- `monitoring/generated/`
- `governance/generated/`

Primary dashboard marts include:

- `data/exports/demo_mart_executive_scorecard.csv`
- `data/exports/demo_mart_channel_performance.csv`
- `data/exports/demo_mart_campaign_performance.csv`

- `data/exports/demo_mart_funnel_performance.csv`
- `data/exports/demo_mart_journey_quality.csv`

If a required mart is missing, the app attempts to rebuild demo marts with `scripts/build_demo_marts.py`. Optional missing marts are shown as unavailable instead of crashing the dashboard.

## Run Locally

Generate or refresh demo marts:

```bash
python3 -B scripts/build_demo_marts.py
```

Start the dashboard:

```bash
streamlit run bi_app/streamlit_app.py
```

## Local QA

Run the lightweight dashboard tests:

```bash
python3 -m pytest tests/test_streamlit_app_data_loader.py -q
```

Run compile checks:

```bash
python3 -m py_compile bi_app/streamlit_app.py
python3 -m py_compile bi_app/data_loader.py
python3 -m py_compile bi_app/metrics.py
python3 -m py_compile bi_app/charts.py
```

## Project Scope

- The dashboard uses generated outputs from the local pipeline.
- Power BI Desktop assets are documented separately in `dashboards/powerbi/` and `semantic_layer/powerbi/`.
- Source-system freshness and pipeline status are based on local generated monitoring outputs.
- Some metrics depend on the marts available in `data/exports/`; missing optional marts are handled gracefully.
