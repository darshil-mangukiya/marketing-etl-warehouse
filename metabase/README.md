# Metabase Optional BI Scaffold

This folder documents a Metabase setup path for the project.

## Suggested Collections

- Executive Marketing
- Channel and Campaign Performance
- Funnel and Attribution
- Targets and Budgeting
- Data Quality Monitoring

## Suggested Questions

1. Monthly spend, revenue, and ROAS by channel.
2. Top campaign spend with waste-budget flag.
3. Funnel conversion from lead to closed won.
4. Target attainment by region and channel.
5. Attribution revenue by model.
6. Customer LTV by acquisition channel.
7. Source quality and rejected-row trends.

## Recommended Permissions

- Executives: view curated dashboards only.
- Analysts: query `mart` and `warehouse` schemas.
- Data Engineering: full access to `ops`, `raw`, and monitoring outputs.
