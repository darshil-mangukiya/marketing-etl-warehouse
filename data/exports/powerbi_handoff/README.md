# Power BI Handoff Package

Import this folder into Power BI Desktop using Get Data > Folder. The CSVs are generated by the local project pipeline and are designed for import-mode report building.

Dimensions: `dim_date`, `dim_campaign`, `dim_channel`, `dim_region`, `dim_device`, `dim_customer_segment`.

Facts/marts: `fact_campaign_performance`, `fact_ad_spend`, `fact_leads`, `fact_conversions`, `fact_revenue_attribution`, `fact_budget_targets`, `mart_campaign_action_recommendations`, `mart_budget_scenarios`.

This handoff folder ships CSV import tables and build documentation that complement the completed editable dashboard at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`. Page captures live in `evidence/screenshots/powerbi/`; rebuild guidance lives in `powerbi_build_steps.md` and `screenshot_checklist.md`.
