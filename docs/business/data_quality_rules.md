# Data Quality Rules


Rules cover duplicate IDs, null spend, invalid dates, missing attribution IDs, orphan conversions, mapping gaps, schema drift, freshness issues, impossible KPI relationships, and source-health warnings.

Quality results should remain visible in executive and BI views so campaign ROI numbers carry context about source reliability.


Data-quality rules run against generated source profiles that intentionally include defects such as duplicate keys, null metrics, and attribution gaps.
