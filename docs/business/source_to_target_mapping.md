# Source To Target Mapping


| Source area | Target asset | Notes |
|---|---|---|
| Paid media spend | campaign and channel performance marts | normalizes spend, clicks, impressions, conversions, and campaign identifiers |
| Web analytics | session and funnel models | supports traffic source and funnel context |
| CRM leads | funnel performance marts | supports lead stage conversion and qualification analysis |
| Sales conversions | revenue and attribution marts | supports booked revenue, conversions, and customer value analysis |
| Marketing targets | target-vs-actual and budget pacing marts | supports spend and revenue target reporting |
| Source quality outputs | data-quality and source-health marts | supports reporting trust and caveats |
| Analyst outputs | campaign recommendations and executive insights | supports decision workflows and stakeholder summaries |


Source-to-target mappings use generated source profiles and local warehouse artifacts so lineage can be reviewed without real customer or platform records.
