# User Stories

1. As a CMO, I want ROAS, CAC, and revenue attainment so I can review marketing efficiency.
2. As a campaign manager, I want campaign ROI and waste-budget flags so I can pause or optimize spend.
3. As finance, I want target-vs-actual and budget pacing so I can explain variance.
4. As sales ops, I want funnel conversion by stage so I can identify handoff leakage.
5. As marketing ops, I want source freshness and rejection summaries so I can trust dashboard refreshes.
6. As a BI developer, I want conformed dimensions and a relationship map so I can build stable reports.
7. As a data analyst, I want SQL/Python outputs so I can investigate campaign drivers.
8. As an executive, I want a compact scorecard so I can identify where decisions are needed.
9. As a channel owner, I want channel drilldowns so I can compare paid search, paid social, email, organic, direct, and referral.
10. As a data engineer, I want logs and watermarks so I can debug incremental readiness.
11. As a BA, I want requirements mapped to KPIs and UAT scenarios so I can validate delivery.
12. As a reviewer, I want clear scope notes and evidence so I can understand the implemented local workflow and deployment extension path.

Acceptance criteria: each story maps to at least one KPI, source/mart, dashboard page, and UAT scenario in the traceability matrix.
