# Non Functional Requirements


1. The demo path must be locally reproducible.
2. Generated outputs must be deterministic enough for tests.
3. Public claims must be traceable to repository artifacts.
4. The project must avoid real client, employer, ad-platform, and customer data.
5. Power BI dashboard artifacts (`.pbix`, screenshots) must identify their generated project data source and Desktop execution mode; cloud publishing is a deployment extension.
6. Validation status must come from logs or generated status files, not hard-coded claims.


Generated source profiles keep local review reproducible without customer or advertising-account records. Performance expectations in this document describe criteria for the local platform.
