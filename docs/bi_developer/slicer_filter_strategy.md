# Slicer Filter Strategy


Slicers should include date, channel, campaign, region, device/platform where available, customer segment, attribution model, and source-health status.

Keep global slicers consistent across pages, hide technical keys from report users, and validate that slicers do not unintentionally blank executive cards because of ambiguous relationships.


These BI documents complement the completed dashboard file committed at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`; rebuild guidance lives in `dashboards/powerbi/BUILD_CHECKLIST.md`.
