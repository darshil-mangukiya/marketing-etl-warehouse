# Refresh And Release Process


Refresh process: run demo marts, generate analyst outputs, generate Power BI handoff, refresh the Power BI folder source, validate KPI totals, capture screenshots manually, and check the publish checklist.

Release checks should reconcile CSV row counts, DAX totals, relationship behavior, slicer behavior, data-quality caveats, and screenshot freshness.


These BI documents complement the completed dashboard file committed at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`; rebuild guidance lives in `dashboards/powerbi/BUILD_CHECKLIST.md`.
