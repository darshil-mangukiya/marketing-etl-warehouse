# Dax Measure Governance


DAX measures are grouped by spend/revenue, ROI, funnel, targets, attribution, campaign actions, and data quality. Comments reference `semantic/kpi_catalog.yml` keys when a governed KPI exists.

Naming standards: use business-readable names, avoid hidden calculated columns for governed KPIs, format currency/percentage/ratio measures consistently, and validate totals against generated marts before publishing screenshots or a report PDF.


These BI documents complement the completed dashboard file committed at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`; rebuild guidance lives in `dashboards/powerbi/BUILD_CHECKLIST.md`.
