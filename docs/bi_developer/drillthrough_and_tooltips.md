# Drillthrough And Tooltips


Recommended drill-through starts from channel and campaign visuals into campaign detail. Drill-through should carry date, channel, campaign, and region where available.

Tooltip pages should show spend, attributed revenue, ROAS, CAC, pacing, target attainment, action priority, and data-quality context so reviewers understand why a campaign was marked scale, pause, or monitor.


These BI documents complement the completed dashboard file committed at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`; rebuild guidance lives in `dashboards/powerbi/BUILD_CHECKLIST.md`.
