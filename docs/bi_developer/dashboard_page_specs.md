# Dashboard Page Specs


Report pages: Executive Marketing Overview, Channel Performance, Campaign ROI Deep Dive, Funnel Conversion, Budget Pacing & Targets, Attribution & Customer Value, and Data Quality & Refresh Health.

Each page should include data-provenance notes, shared slicers, KPI cards, trend and context visuals, a detail table, and a clear decision output.


These BI documents complement the completed dashboard file committed at `dashboards/powerbi/p2_marketing_performance_dashboard.pbix`; rebuild guidance lives in `dashboards/powerbi/BUILD_CHECKLIST.md`.
