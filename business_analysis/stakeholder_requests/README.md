# Modeled Stakeholder Request Workflow

This lightweight portfolio workflow shows how ambiguous business questions become controlled analysis. It records modeled scenarios only; it does not represent actual stakeholder meetings, approvals, adoption, or sign-off.

```text
Business Request → Clarification → Analytical Definition → Data Validation
→ Analysis → Finding → Recommendation → Decision / Follow-up
```

## Files

- `analytics_request_template.md` defines the request and evidence contract.
- `clarification_question_template.md` keeps scope, definitions, grain, comparison, and decision authority explicit.
- `stakeholder_request_log.csv` tracks the six modeled requests through the lifecycle.
- `decision_log.csv` records portfolio-case-study dispositions, never actual management approval.
- `action_tracker.csv` records human-review follow-ups without implying real operational execution.

The completed evidence packages are in [`analytics_requests/`](../../analytics_requests/README.md).
