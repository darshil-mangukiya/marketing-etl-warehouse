# Marketing ETL Platform v1.0.0

## Release Summary

Version `v1.0.0` packages the local marketing data platform as a complete release artifact:

- multi-source source simulators
- API, batch, and file ingestion
- local S3-style lake zones
- PostgreSQL warehouse loading
- dbt staging, intermediate, dimensional, and reporting models
- validation, rejected-record, and audit outputs
- semantic model and Power BI-ready assets
- executive, planning, governance, and observability reports
- static evidence site

## Validation

Release readiness is based on the Local Quality Gate plus optional warehouse integration:

- smoke pipeline
- Great Expectations-style checkpoint
- source contracts
- mart generation
- metadata generation
- semantic package generation
- governance checks
- pytest
- dbt parse

## Included Evidence

The release package includes generated HTML reports, SVG visual evidence, metadata manifests, governance outputs, and static dbt documentation when available.
